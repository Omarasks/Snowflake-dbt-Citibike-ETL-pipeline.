## End-to-End Data Pipeline: NYC Bike-Share Demand Through Weather Pattern Analysis

![Citi_Bike_Landing_page_Hero_3x](https://github.com/user-attachments/assets/0b5bc7ff-201b-4b6d-99ad-c5d871cc66c5) 

The goal of this project is build an ETL pipeline that will allow data analyst build a PowerBI dashboard to make analysis to discover weather patterns with Citi-bike rides across New York City . 

The data source consist of a semi- structured JSON 2019 weather dataset stored in a public s3 bucket, and a publicly available Citi-bike rides in 2019. The analysis also answers questions like Where do Citi Bikers ride? When do they ride? How far do they go? Which stations are most popular? What days of the week are most rides taken on?. 

We begin data ingestion in snowflake data warehouse, transformations with Dbt, visualizations in PowerBI.
